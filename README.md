## 🎯 Motivação e Propósito

No desenvolvimento front-end moderno, a agilidade é crucial. O propósito deste projeto foi dominar o uso do **Bootstrap**, o framework CSS mais popular do mundo.

O projeto resolve o problema de construir um site visualmente complexo (com colunas, cards e navegação adaptável) em curto prazo, garantindo que o layout funcione perfeitamente em dispositivos móveis (Mobile First) sem a necessidade de escrever milhares de linhas de CSS manual.

## 🛠️ Tecnologias Utilizadas

A stack tecnológica prioriza a eficiência e a padronização visual:

* **[Bootstrap 5](https://getbootstrap.com/):** Framework principal utilizado para:
    * **Grid System:** Criação de colunas responsivas para o cardápio.
    * **Components:** Uso de Navbar, Cards (para os produtos), Modais e Botões estilizados.
    * **Utilities:** Classes utilitárias para espaçamento (margins/paddings) e tipografia.
* **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estrutura semântica.
* **[CSS3 Customizado](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Estilos pontuais (`main.css` ou `style.css`) para sobrescrever o padrão do Bootstrap e dar identidade visual única à marca (cores, fontes específicas).
* **Git:** Controle de versão.
